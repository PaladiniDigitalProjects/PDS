== Description ==

Introducing the Masonry Gallery Block, a single block plugin that extends the core Gallery block in WordPress. With this plugin, you can easily create a beautiful and responsive masonry layout for your galleries. This plugin adds a masonry variation to the core Gallery block, allowing you to showcase your images in a unique and visually appealing way. It's fully responsive and works seamlessly with all themes. Give your galleries a fresh, modern look with the Masonry Gallery Block.
